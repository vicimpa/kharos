# Адаптивный интерфейс

Перенос макета «Адаптивный интерфейс» (холст «Kharos — дизайн интерфейса»,
https://claude.ai/artifact/5DZzV42DoMDcfiDP1DMSr1, страница «Адаптивный интерфейс»: `Adaptive.dc.html`, правила —
`AdGuide.dc.html`, стили — `adaptive.css`) в панель игрока `mods/base/ui/hud.luau`.

Суть макета: одна разметка на все экраны и все виды ввода. Полос во всю ширину нет, карта — на весь экран, интерфейс —
плавающие окна по краям, и каждое появляется, только когда нужно. Раскладку решает размер окна, дополнительные элементы
управления — нынешний вид ввода (мышь, касание, геймпад).

## Этапы

### 1. Окна вместо полос: компьютер, мышь [сделано]

- Верхняя полоса — два блока по углам (высота 40, отступ 6): слева кредиты с доходом, энергия с полоской нагрузки,
  запас; справа часы, кнопка исследований (название темы, %, полоска), меню.
- Мини-карта — слева сверху под левым блоком (в макете — слева снизу; перенесено, чтобы низ слева был свободен),
  сторона из настроек, не больше трети короткой стороны экрана.
- Первые шаги — справа сверху компактной карточкой (300): свёрнутая — «2/12 Название ▸» и деления, касание
  разворачивает: что сделать, зачем, «Показать». По умолчанию свёрнута — карта важнее. Уведомления — под ней.
- Нижние окна: справа снизу команды 4×3 (ячейка 172×44), выбранное (360) слева от них или над ними на узком экране.
- Подсказка ячейки и лист подробностей по долгому касанию (правой кнопкой) — прямо над ячейкой: карточка, кнопка
  действия и ✕.
- Ничего не выбрано — окна команд нет; режим (стройка, патруль) — вместо команд, с «Отмена» и «Готово».

### 2. Содержание окон

- Стройка — разделы вкладками над сеткой (вместо страниц с «Назад»), отметка нового раздела.
- Ничего не выбрано — сводка базы плитками: главное здание, армия, строители, грузовики, лаборатории, космопорт.
- Отряд — плитки видов с числом; здание — уровень, строки склада полоской.
- Группы строкой над мини-картой: значок, цифра, сколько.

### 3. Вид ввода

- Движок: `c.input.mode` — `mouse` | `touch` | `gamepad` по последнему вводу, настройка «Управление: само · мышь ·
  касание · геймпад».
- Размеры по виду: кнопки 36/44/40, ячейки 44/56/52, верх 40/48/44. При касании и геймпаде значков клавиш и пустых
  ячеек нет.
- Касание: кнопки поля (группы, зоны стройки, сигнал, «в очередь»).

### 4. Стоя и телефон [основа сделана]

- Стоя: команды доком снизу во всю ширину, выбранное над ним; уже 120 на ячейку — ячейки столбиком (значок,
  название в две строки, цена в углу), высота 68. Карточка шагов — справа от мини-карты, уведомления и награды — под
  ними; открытий видно одно и «+N».
- Ниже 500 (телефон лёжа): команды колонкой справа (2×6), выбранное слева снизу; пока что-то выбрано, карточки шагов
  нет.
- Осталось: мини-карта кнопкой на коротком экране стоя, полоса в два ряда на узком.

### 5. Геймпад

- Движок: геймпад на компьютере (gilrs) и в браузере (Gamepad API через web-sys).
- Курсор посреди поля левым стиком, камера правым, рамка фокуса в сетке крестовиной, LB/RB — разделы, кольцо групп по
  LT, строка кнопок под полосой.
